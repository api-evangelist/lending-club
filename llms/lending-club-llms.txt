# LendingClub (Happen Bank)

> LendingClub is a US consumer-finance company and digital bank, founded in 2006 as a
> peer-to-peer marketplace lender and now a national bank after its 2021 acquisition of
> Radius Bancorp. In 2026 it rebranded as Happen Bank, N.A. (a subsidiary of Happen, Inc.)
> and moved its web presence from lendingclub.com to happen.com. LendingClub does not
> currently operate a public developer program: there is no developer portal, API
> reference, OpenAPI description, SDK, or event/webhook surface. Its former public
> Investor API served the retail Notes marketplace, which was retired in December 2020.

## Status

- No public API documentation, developer portal, or API reference is published.
- No OpenAPI, AsyncAPI, GraphQL, or Protobuf specification is available.
- No first-party SDKs, CLI, MCP server, or Agent Skills are published.
- No `.well-known` discovery documents are served (see well-known/lending-club-well-known.yml).
- The legacy host `https://api.lendingclub.com` still answers `/api/investor/v1/...`
  with HTTP 401, but the interface is undocumented and closed.
